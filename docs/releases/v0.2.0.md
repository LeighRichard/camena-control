# v0.2.0 发布说明

发布日期：2026-04-07

## 概览

`v0.2.0` 是面向当前实物方案整理的一版硬件对齐版本，核心目标不是继续沿用“三轴步进”假设，而是把整套控制链改成：

- `pan / tilt`：二维云台 PWM 舵机
- `rail`：独立步进滑轨
- `Jetson <-> STM32`：协议保持兼容，前后端参数边界重新对齐

这版同时补齐了可交付固件产物、构建脚本稳定性，以及面向现场装配的接线与烧录文档。

## 本版本重点

### 1. STM32 运动架构改为混合三轴

- `pan / tilt` 从步进轴改为 PWM 舵机输出
- `rail` 保留步进驱动控制
- `SET_VELOCITY` 继续兼容 Jetson 发送的 `steps/s`
- STM32 内部对 `pan / tilt` 自动换算为舵机角速度
- `STOP` 时舵机保持当前位置，`rail` 停止脉冲输出

对应实现：

- `stm32/CameraControl/Core/Src/motion.c`
- `stm32/CameraControl/Core/Src/tim.c`
- `stm32/CameraControl/Core/Src/main.c`
- `stm32/CameraControl/Core/Src/safety.c`
- `stm32/CameraControl/Core/Src/stm32f4xx_it.c`

### 2. 机械范围按实物云台重新定义

当前固件与上位机统一采用以下范围：

- `pan`：`-135° ~ +135°`
- `tilt`：`-110° ~ +110°`
- `rail`：`0 ~ 500 mm`

说明：

- 角度命令单位仍为 `0.01°`
- 滑轨位置单位仍为 `0.01 mm`
- Jetson 侧协议和 Web 调用方式不变，但位置校验已按新范围收敛

### 3. Jetson 侧同步完成边界对齐

- 更新了 `pan / tilt` 的合法位置范围
- Web 手动移动接口增加了机械范围校验
- 避免前端发送超过云台物理行程的目标角度

对应实现：

- `jetson/src/comm/unit_converter.py`
- `jetson/src/web/app.py`
- `jetson/tests/test_unit_converter.py`

### 4. 固件构建与产物生成更稳定

- 修复了 Windows 中文路径下 `objcopy` 生成 `hex / bin` 的稳定性问题
- 构建脚本不再因重定向执行环境的假失败而误报
- 现在可稳定产出：
  - `CameraControl.elf`
  - `CameraControl.hex`
  - `CameraControl.bin`

对应实现：

- `stm32/CameraControl/CMakeLists.txt`
- `stm32/CameraControl/scripts/FirmwareTools.ps1`
