# v0.1.0 发布说明

发布日期：2026-04-03

## 概览

`v0.1.0` 是当前仓库的第一个可对外说明的整理版本，重点不是“新增一个单点功能”，而是把 Jetson 主控、STM32 固件、协议文档、构建流程和联调可视化一起拉到了一个更容易接手和继续开发的状态。

## 本版本重点

### 1. STM32 固件侧

- 清理了协议、串口通信和配置分发中的历史乱码注释
- 把 `CONFIG` 参数从魔法值处理改成具名 ID 和清晰分发
- 对齐了 Jetson 侧约定的限位、速度和配置语义
- 增加了更稳定的固件构建与烧录脚本：
  - `stm32/CameraControl/build_firmware.ps1`
  - `stm32/CameraControl/flash_firmware.ps1`
  - `stm32/CameraControl/scripts/FirmwareTools.ps1`
- 现在可以稳定产出 `elf / hex / bin`

### 2. Jetson 主控侧

- 补齐了 `CONFIG` 参数打包和具名发送接口
- 修正了 Web 层和通信层之间的调用兼容问题
- 增加了 `/api/motion/config`
- 增加了串口诊断能力：
  - 协议语义日志
  - 原始十六进制帧日志
  - 最近 N 条通信历史缓存
  - `/api/comm/diagnostics`
  - `/api/comm/diagnostics/clear`
- Web 前端新增串口诊断面板

### 3. TensorRT 检测链

- Jetson 启动时现在会主动尝试加载检测模型，而不是只创建检测器对象
- 目标检测 TensorRT 状态已经接入系统状态和前端页面
- 现在可以在 Web 状态里看到：
  - 是否已加载
  - 是否是模拟模式
  - 当前推理引擎
  - TensorRT 是否可用
  - 模型路径与错误原因

### 4. 文档与联调

- 新增 Jetson 与 STM32 端到端串口链路文档
- 根目录 README 已整理为适合 GitHub 首页展示的版本
- STM32 文档补上了构建、协议、参数表和联调约束

## 适合的使用方式

如果你现在要继续开发，建议按下面顺序开始：

1. 先看根目录 `README.md`
2. 再看 `stm32/README.md`
3. 然后结合 `docs/jetson_stm32_comm_flow.md` 做联调
4. 实机上确认 Jetson 的模型文件、相机、串口和 TensorRT 环境

## 已验证内容

- STM32 固件可生成构建产物，并已整理为可直接执行的脚本流程
- Jetson 前端脚本已经过语法检查
- GitHub 远程仓库已同步当前代码与文档版本
